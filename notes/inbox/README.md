# Human Inbox

Hier landen schnelle menschliche Notizen, Ideen, Fragen und unfertige Mitschriften.

Der Agent darf diese Notizen als Input verwenden, soll sie aber nicht stillschweigend ueberschreiben. Wenn eine Notiz dauerhaft relevant ist, wird sie in passende Seiten unter `wiki/` integriert.
